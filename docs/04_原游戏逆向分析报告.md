## 二、破解过程（XXTEA Key）

### 2.1 关键突破
XXTEA 密钥成功提取：**`504340af-d6c2-4b`**

来源：`libcocos2djs.so` 中 `Cocos Game.` 字符串之后的 UUID 字符串。

### 2.2 为什么之前失败
- 最初用 Python 的 `xxtea` 库解密报 `illegal padding`，误以为 key 不对
- 实际原因是 **Python xxtea 库与 Cocos 用的 `xxtea-node` 实现不兼容**
- 换成 `xxtea-node` 后，用同一 key 完美解密

### 2.3 解密流程
```
jsc 文件 → xxtea.decrypt(data, key) → (若 gzip/zlib) → inflate → 明文 JS
```

## 三、宠物系统（原版）

### 3.1 图鉴数据（monstercfg，157 种）
每条含：
- `name`：名称（如 黄蜂、哥布林、寒冰翼龙、僵尸、食尸鬼…）
- `bp`：基础属性 6 维（`[体质,力量,灵巧,敏捷,智力,幸运]`）
- `element`：元素抗性/属性
- `skinres`：皮肤资源名（如 `AlienInsect1`、`Goblin1`、`DragonBlue`、`Zombie2`）
- `babygl`：捕捉基础概率

### 3.2 宠物对象逻辑（petobj）
- **创建/捕捉**：`initwithid`（支持 boss 判定、闪光变异 `lighting`）
- **升级**：`lvup`（消耗 `500×等级` 金币）、`gainexp` 经验获取
- **所需经验**：`maxexp = 等级³`
- **属性成长**：`setbp`（基于基础属性 + boss/闪光加成 + 转生 + 随机浮动）
- **技能**：最多 6 个，`learnskill`/`forgetskill`
- **转生**：每 100 级可转生一次，`dozhuanshen`
- **洗练**：消耗道具 `30003` 重置属性
- **存档**：`encode`/`initwithsave`

## 五、装备系统（原版）

### 5.1 物品配置（gameConfig.itemConfig）
装备条目字段：
- `id`：物品 ID
- `name`：名称（光之圣剑、奥丁战铠、秘银铠甲、皮质裤子…）
- `type`：类型（1武器 / 2护甲防具 / 3材料消耗品）
- `subtype`：子类型（武器/裤子/图纸/材料…）
- `qulity`：品质（1~5）
- `fixproperty`：固定属性（格式 `属性ID:数值:随机浮动`，如 `9:100:10` 攻击+100）
- `fixskill`：附带技能
- `cost`：价格
- `logiclv`：需求等级
- `icon`：图标资源

### 5.2 装备对象逻辑（equipobj）
- **属性成长系数表**：每种属性有不同成长（如 maxhp×30、atk/matk×10、cri×1、xixue×1）
- **强化档位**：数组控制强化成长
- **品质判定**：根据随机 + 配置品质
- **套装/词条**：多属性随机

## 八、二开能力
基于已还原的源码和配置，可进行：
1. **修改数值**：直接改 `monstercfg`（宠物属性）、`itemConfig`（装备数值）
2. **新增宠物/装备**：在配置里加条目
3. **新增玩法**：基于 `gamelogic`/`gameManager` 扩展
4. **重新打包**：用 XXTEA key `504340af-d6c2-4b` 重新加密 jsc，或用 Cocos Creator 重编译
