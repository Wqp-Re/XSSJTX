**日期**：2026-08-21
**说明**：在战斗界面新增**速度倍率开关按钮**，支持 2x/5x/10x/50x/100x 战斗加速。APK 已本地归档。

| 版本 | 更新项 | 涉及模块 | 类型 |

| v1 | 调用 `cc.kSpeed(n)` 实现全局战斗加速 | `gameUI` + `Utils`(已有 kSpeed) | 增强 |

**实现细节**
- 加速原理：`cc.kSpeed(n)` 设置全局 `cc.director._kSpeed = n`，每帧 `_deltaTime *= _kSpeed`，所有依赖 deltaTime 的战斗逻辑（移动/攻击/技能CD/Buff）同步加速
- 按钮位置：战斗界面右上角（`size.width/2-70, size.height/2-60`）
- 按钮样式：`cc.Graphics` 圆角黑底 + 黄色描边 + 黄色文字，显示当前倍率（如"速度 5x"）
- 默认 1x（不加速），退出战斗自动恢复 `cc.kSpeed(1)`

**构建产物**
- `workspace/builds/apk_v1/像素世界探险_v1加速版.apk`（33.4MB）
- 重新加密：`xxtea(js明文, key=504340af-d6c2-4b)`，无 gzip

## v9.2（修复退出战斗按钮消失）
**日期**：2026-08-21

**根因**：v9.1 的轮询在按钮创建成功后就 `clearInterval` 停止。退出战斗场景切换，按钮节点被销毁，但轮询已停止，不再重建 → 按钮没了。

**修复**：改为**持续轮询（永不停止，每1秒检查）**，每次检查按钮是否还在当前 Canvas 下：
- 在 → 不处理
- 不在（场景切换）→ 重新挂载到当前 Canvas
- 已销毁 → 重建新按钮

**实测**（模拟器）：
- 第一次进入：按钮在（红色像素34）
- 按返回退出战斗：按钮逻辑正常
- 重新进入战斗：按钮还在（红色像素38）
- 游戏正常（TypeError=0, FATAL=0）

## 热修：深渊之塔连续闯关（2026-09-01）

**问题**：深渊之塔打死boss后只发币+层+1，场景停滞，无连续闯关（与肉鸽对比：肉鸽选完遗物后 `loadScene("game")` 进下一层，深渊漏了这步）。

**修复**（v11 + vD 同步）：

```js
} else if (cc.abyssMode && this.isboss) {

}
```

## 热修：全局加速被减速buff覆盖（2026-09-01）

**问题**：加速按钮档位 `_spArr=[1,5,20,50,100]`，5倍有感知，20/50/100倍几乎无效。

**根因**：全局加速只有一个因子 `cc.director._kSpeed`（缩放 `calculateDeltaTime`）。减速类buff（冰冻/缠绕/减速怪，`cfg.timescale<1`）应用/移除时直接 `cc.kSpeed(timescale)` / `cc.kSpeed(1)`，把**用户加速档整个覆盖**成 timescale 或 1。战斗中一旦触发减速buff，加速档丢失；buff结束后被强制复位为1而非用户档位，导致高倍率档位形同虚设。

**修复**（v11 + vD 同步）：把"用户加速档"与"减速buff"解耦为两个独立因子相乘：
- 新增 `cc.director._kBuff`（默认1）；`cc.kDebuff(t)` 设置减速因子。
- `calculateDeltaTime`: `this._deltaTime *= this._kSpeed * this._kBuff;`
- 减速buff应用 `cc.kSpeed(timescale)` → `cc.kDebuff(timescale)`；移除 `cc.kSpeed(1)` → `cc.kDebuff(1)`；UI关闭同理。
- `_spApply` 切档时复位 `_kBuff=1`，确保 20/50/100 倍始终生效（减速buff期间为 timescale×用户档，符合预期）。

**验证**：v11/vD 重新打包 ACORN OK / apktool 0 / sign 0。

## 热修：加速档位调整 + 高倍率攻击穿模（2026-09-01）

**需求**：加速档位改为 `[1,3,5,10,15,20,30,50,100]`；高倍率（20+）打boss无攻击感、不掉血。

**根因**：子弹（bullet 类）`update` 仅在 `timetoatk<=0` 时检测**当前帧位置**命中（逐帧点重叠），且每帧最多检测一次。高倍率下 `_kSpeed` 放大 deltaTime → 子弹一帧位移远超 boss 体积（穿模 miss），且攻击频率被 60fps 锁死（无法 ×20）。所以 5 倍仍命中掉血、20 倍像没攻击。

**修复**（v11 + vD 同步）：
1. 加速档位：`cc._spArr=[1,3,5,10,15,20,30,50,100]`。
2. 子弹 `update` 子步进：单帧 dt 拆成 ≤0.05s 小步，每步移动+命中检测（`steps = ceil(t/0.05)`）。既防高速穿模（每步位移小，圆-圆重叠命中），又让攻击频率随倍率线性提升（20倍≈每帧多次命中）。保留 `timetoatk`/`movedelay`/`dirspeed`/`rotateuser`/`autodir2` 语义，加 `void 0===this.timetoatk` 防御。

**验证**：v11/vD 重新打包 ACORN OK / apktool 0 / sign 0。
